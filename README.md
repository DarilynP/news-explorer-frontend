# 📰 News Explorer

**News Explorer** is a responsive application that allows users to search for the latest news based on a keyword. Users can register, log in, save articles, and manage their own personal collection of news stories.

---

## 🚀 Features

- 🔍 Keyword search using News API
- 👤 User registration and login
- 💾 Save and delete favorite articles
- 🛡️ Protected routes (JWT authentication)
- 🌐 Fully responsive design (mobile/tablet/desktop)
- 💬 Tooltip and visual UI feedback

---

## 🛠️ Tech Stack

- **Frontend**: React,
- **Routing**: React Router
- **API**: NewsAPI.org, Custom backend (Node.js/Express)
- **Auth**: JWT tokens stored in `localStorage`
